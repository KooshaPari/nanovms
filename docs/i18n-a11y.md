# nanovms i18n & a11y

i18n via `golang.org/x/text/language` + `golang.org/x/text/message`, a11y via terminal best practices.

## Stack

- `golang.org/x/text/language` - BCP-47 language tags
- `golang.org/x/text/message` - i18n catalog
- `golang.org/x/text/currency` - locale-aware currency
- `github.com/mattn/go-isatty` - detect interactive vs piped

## Translation files

`internal/i18n/locales/<lang>/catalog.gotext`:

```
# en-US/catalog.gotext
msgid "sandbox.created"
msgstr "Sandbox {Name} created in {Duration}s"

msgid "secret.accessed"
msgstr "Secret {Name} accessed"
```

`internal/i18n/locales/es-ES/catalog.gotext`:

```
msgid "sandbox.created"
msgstr "Arenero {Name} creado en {Duration}s"
```

## Usage

```go
import "golang.org/x/text/message"

p := message.NewPrinter(language.Spanish)
p.Printf("sandbox.created", "Name", "test", "Duration", 5)
// Output: "Arenero test creado en 5s"
```

## Locale fallback

`en-US` is the default. Missing key in target locale falls back to `en-US`. Missing in both logs a warning + returns the key name.

```go
p := message.NewPrinter(language.Match(makeLang("es-MX")))
// es-MX -> es-ES -> en-US
```

## CLI a11y

```go
// Always pair color with text
fmt.Printf("[OK] Sandbox %s created\n", name)  // not just green text
fmt.Printf("[FAIL] %s\n", err)

// NO_COLOR support
if os.Getenv("NO_COLOR") != "" {
    noColor = true
}

// High contrast: bold + text
fmt.Println("Error: connection refused")  // not just red

// Screen reader friendly
fmt.Println("Sandbox test created. Press Enter to continue.")
```

## Width calculation (CJK, emoji)

```go
import "github.com/mattn/go-runewidth"

w := runewidth.StringWidth("hello")      // 5
w := runewidth.StringWidth("日本語")    // 6 (fullwidth)
w := runewidth.StringWidth("👨‍👩‍👧")    // 2 (wide)
```

Use this for table alignment in CLI output.

## TUI screen reader (charmbracelet/lipgloss)

```go
import "github.com/charmbracelet/x/ansi"

// Mark interactive elements
fmt.Println(ansi.Style{}.Bold(true).Render("Sandbox created") + " — see log")
```

## Test

```go
func TestSandboxCreatedTranslation(t *testing.T) {
    p := message.NewPrinter(language.Spanish)
    got := p.Sprintf("sandbox.created", "Name", "x", "Duration", 1)
    if got != "Arenero x creado en 1s" {
        t.Errorf("got %q", got)
    }
}
```

## Coverage target

- 100% of user-facing strings in `internal/i18n/locales/en-US/`
- Each non-en-US locale covers at least 80% of en-US keys
- CI fails PR if locale coverage drops
